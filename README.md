
Este juego ha sido desarrollado como parte de una tarea del grado del ciclo de Microsistemas y Redes, dentro de la asignatura Estructuras de Control en Python.

La mecánica del juego consiste en controlar un paracaidista que debe evitar chocar contra los enemigos que aparecen durante la partida. El objetivo es sobrevivir el mayor tiempo posible, esquivando los obstáculos para conseguir la puntuación más alta. El sistema de puntuación se basa en el tiempo: cuanto más tiempo mayor será la puntuación.

Para su creación, he tomado como referencia juegos conocidos como Subway Surfers y Dino Chrome, utilizando sus mecánicas como inspiración para desarrollar mi propia versión. El juego cuenta con un estilo visual Pixel Art, con diseños, gráficos y elementos creados por mí, aportándole una identidad propia y original.

El objetivo principal de este proyecto es aprender los fundamentos de la programación en Python mediante la programación por bloques, comprendiendo la lógica del juego y el funcionamiento de sus diferentes elementos antes de trasladar esa lógica al código Python. De esta forma, se facilita el aprendizaje progresivo de la programación, pasando de una representación visual de las instrucciones a su implementación mediante código.
